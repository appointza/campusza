# campusza

School management platform (Campusza API + school-hub frontend).

## Local setup

- **API:** `campusza_server/Campusza` — copy connection strings and mail settings into `appsettings.Development.json` (not committed).
- **Web:** `school-hub` — see `school-hub/README.md`.
- **Build:** `BUILD.md`, `DEPLOY.md` at repo root.

Do not commit Firebase service account JSON, AWS keys, or production credentials.
